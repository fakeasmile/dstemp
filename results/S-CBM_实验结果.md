# S-CBM 实验结果记录

数据：TOXICN 官方 split（train 9600 / test 2411，其中 train 再切 10% 作 dev）
指标：dev 选阈值 → test 评一次。**AUC 无阈值，是可比的稳定量；F1 受阈值抖动影响大。**

## 1. 主表

| 变体 | λ | 词法维 | dev F1 | test F1 | **test AUC** | 概念保真度 |
|---|---|---|---|---|---|---|
| d1 黑箱 | — | — | 0.8224 | **0.8125** | **0.8917** | — |
| d2 自由瓶颈 | 0 | 0 | 0.8063 | 0.8007 | 0.8778 | **−0.132** |
| d3 锚定瓶颈 | 0.5 | 0 | 0.8297 | 0.8153 | 0.8482 | +0.306 |
| d4 锚定+词法 | 0.5 | 50 | 0.8285 | 0.8077 | 0.8594 | +0.539 |
| d4 词法消融（推理 lex=0） | 0.5 | 50 | 0.8267 | 0.8066 | **0.8639** | — |
| d4 锚定+词法 | 0.5 | 337 | 0.8069 | 0.7855 | 0.8310 | — |
| d1 黑箱 + 外部语料 | — | — | 0.8184 | 0.8074 | 0.8912 | — |

参照：ToxiCN 公开 SOTA ≈ 0.838 Macro-F1。

## 2. 关键读数

### 2.1 F1 与 AUC 严重冲突

d3 的 F1 最高（0.8153，甚至高于黑箱），但 AUC 最低之一（0.8482）。
d1 的 AUC 最高（0.8917），F1 却排第二。

**结论：在 dev=960 上选阈值、test=2411 上评 F1，阈值自由度足以让 F1 摆动 ±0.01。
F1 差异小于 0.01 时不应作结论，应以 AUC 为准。**

### 2.2 瓶颈的真实代价在 AUC 上可见

| 对比 | ΔF1 | ΔAUC |
|---|---|---|
| d1 → d2（自由瓶颈） | −0.012 | **−0.014** |
| d1 → d3（锚定瓶颈） | +0.003 | **−0.043** |

所以：**瓶颈损失 0.014 AUC，把维度锚回可命名概念再损失 0.029 AUC。**

（此前基于 d1 仅 1 epoch 得出的"瓶颈不损失精度"结论，已被 d1 跑满 4 epoch 后的 0.8917 AUC 推翻。）

### 2.3 锚定的收益很薄

λ=0.5 时概念保真度只有 **0.306** —— 付出 0.029 AUC，换来一个与目标概念相关性 0.31 的向量。

### 2.4 保真度可以被"架空"而虚高

d4 加了 50 个词法维后，保真度从 0.306 跳到 **0.539**，同时 AUC 回升到 0.8594。
最可能的解释：分类器把决策交给词法维，z 因此可以自由地去满足锚定项。

**这意味着保真度不能单独作为可解释性的证据。** 必须配合：
- 分类器权重在 z 与 lex 上的分配（`[diag] ||w_z|| vs ||w_lex||`）
- 推理时把 lex 置零的消融（`--lex_ablate`）

### 2.5 词法维数量敏感

337 维 → 0.7855 / 0.8310；50 维 → 0.8077 / 0.8594。
说明此前 d4 的性能塌陷主要是弱词条导致的过拟合，不是词法通道本身无效。

## 3. 0.84 的结构性位置

黑箱 d1 = 0.8125 F1 / 0.8917 AUC，距公开 SOTA 0.838 还差 2.5 点。
**即：在这套训练配置下，连黑箱都到不了 0.84。**

因此 0.84 是编码器/数据规模问题，不是瓶颈问题。任何"用概念层方法冲到 0.84"的路径都先要有一个 ≥0.84 的黑箱。

## 4. 词法消融：权重范数不是归因

`--lex_ablate` 把推理时的 50 个词法维置零：

| 条件 | test F1 | test AUC |
|---|---|---|
| 正常（z + 50 词法） | 0.8077 | 0.8594 |
| 消融（只留 z） | 0.8066 | **0.8639** |

分类器权重：`||w_z|| = 0.3754`，`||w_lex|| = 0.4653`，**词法占 55.3%**。

但消融后 AUC 反而略升。结论：
1. **词法维对决策的贡献约为 0**（甚至微负），判断由 z 承担。
2. **权重范数不是有效的概念重要性度量** —— 55% 的权重可以是 0 贡献，因为词法维与 z 高度共线。
   这直接质疑了 CBM 领域常用的"看线性层权重解释概念重要性"做法。

同时：d4 消融后的 z（0.8639）比 d3 的 z（0.8482）高 0.016 AUC，保真度也更高（0.539 vs 0.306）。
说明**训练时存在一条冗余的词法旁路，会让概念编码器学得更好**（充当正则/辅助任务），
而推理时并不需要它。这可以作为一种技巧："训练有旁路、推理无旁路"。

## 5. 外部语料无效

d1 + 3.3 倍外部语料（42,286 条，预训练 1 epoch，耗时约 10 分钟）：

| | test F1 | test AUC |
|---|---|---|
| d1 | 0.8125 | 0.8917 |
| d1 + external | 0.8074 | 0.8912 |

**AUC 无变化，F1 略降。** 且阈值跳到 0.045（概率分布被外部标签改写）。

可能原因：外部三套数据集的毒性定义与 ToxiCN 不同（跨数据集同文异标率 21.7% 已证实），
预训练学到的是另一种"毒性"概念，迁移无效。这是一个有价值的负面结果。

## 6. 0.84 的判决

| 事实 | 数值 |
|---|---|
| 黑箱（MacBERT-base，4 epoch） | 0.8125 F1 / 0.8917 AUC |
| 加外部语料 | 无提升 |
| 加训练轮次 | epoch 2 最佳，之后过拟合 |
| 公开 SOTA | 0.838 F1 |

**在 MacBERT-base + 现有训练配置下，0.84 不可达。现实上限约 0.82–0.83。**

## 7. 当前可支撑的最强主张

> 概念瓶颈的真实代价不在宽度，而在"把维度钉回可命名概念"这一步。

| 配置 | test AUC | 相对黑箱 |
|---|---|---|
| 黑箱 | 0.8917 | — |
| 26 维自由瓶颈 | 0.8778 | −0.014 |
| 26 维锚定瓶颈 | 0.8482 | −0.043 |
| 锚定 + 冗余旁路训练（推理不用旁路） | 0.8639 | −0.028 |

配套的四条方法论发现，全部已有数据支撑：
1. 自由瓶颈的维度与目标概念相关性 **−0.13** → "瓶颈"不等于"概念"
2. 保真度可被冗余通道虚高（0.306 → 0.539），必须配推理时消融
3. 权重范数不是归因（55% 权重 ≈ 0 贡献）
4. 跨数据集标注冲突 21.7%，且外部数据迁移无效
