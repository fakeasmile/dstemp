# v8 概念向量数据核查与结论

> 数据：`data/processed/TOXICN/v8_glm-4-9b-chat/`（glm-4-9b-chat，26 个概念条目）
> 脚本：`scripts/analyze_v8.py`、`scripts/diagnose_v8.py`、`scripts/plot_v8.py`
> 环境：conda `toxicnew`

## 0. 与方案文档 v3 的口径差异（先修正前提）

| 项目 | 方案 v3 所述 | 实际 v8 数据 |
|---|---|---|
| 概念数 | 180 维 | **26 维** |
| 矩阵形状 | 9600×183 | 9600×26 |
| 主结果 Macro-F1 | 0.8018（v7 嵌套 CV） | 0.7988（v8, XGB 5 折） |

v8 用 **1/7 的概念数**复现了 v7 的性能（0.7988 vs 0.7989）。这本身就是最重要的发现之一：**名义概念数从 180 降到 26，下游不降。**

## 1. 概念层质量

- 26 个概念的单变量 AUC 全部 ≥ 0.670，其中 22 个 ≥ 0.75；最高 B01（群体敌意）= 0.856。
- 没有退化维度、没有死概念、无 NaN（值域 [1e-6, 0.999]）。
- 平均 |Pearson| = 0.525，|r|>0.8 的概念对 28/325，最强 B01–B07 = 0.898。
- 有效秩（标准化后，熵定义）= **19.12** / K=26；stable rank = 13.0；PC1 解释 57.2%；累计 90% 方差需 10 个主成分。
- 每条文本 26 个概念平均有 22 个不同取值 → **题目确实在影响输出**，不存在"模型忽略问题、26 列同值"的系统性退化。

结论：概念集在统计意义上是健康的，不是噪声堆。

## 2. 但标签相关信息近似 1 维（核心发现）

| 输入 | Macro-F1 (5 折 CV) |
|---|---|
| 最强单概念 B01 | 0.7788 |
| **mean(P_yes)，1 维** | **0.7810** |
| PCA-5 | 0.7837 |
| PCA-10 | 0.7866 |
| LR，26 维 | 0.7902 |
| MLP(256,128)，26 维 | 0.7954 |
| **XGBoost，26 维** | **0.7988** |
| XGBoost，超大容量 (1200×6) | 0.7937（更差） |
| HistGB | 0.7905 |

- 26 维相对 1 维只多 **+0.018**。
- 加大模型容量无收益甚至变差 → 容量已饱和，**限制因素在 ẑ 的信息量，不在分类器**。
- 多种子（5 个划分）XGB = 0.7971 ± **0.0016**（文档的 ±0.0004 偏窄约 4 倍）。
- L1 在 C=0.03 仍保留 16/26 个概念 → 没有"少数高价值概念"的稀疏结构，但置换重要性集中在 B01/B07/B06/B02/A03。

## 3. 逐概念纠错在原理上不可能提升下游性能

若 z̃ = g(ẑ)，则 ẑ → z̃ 构成马尔可夫链，数据信息不等式给出 I(z̃; y) ≤ I(ẑ; y)。
任何 ẑ 上的分类器都能复现 z̃ 上的对应分类器，故 **z̃ 的最优可达性能不超过 ẑ**。

实证支持：
- **违规诊断上界**：逐概念用 gold toxic 标签做 isotonic 重标定 + LR = **0.7960**，低于原始 XGB 的 0.7988。
- 下游已饱和（见 §2），连"帮助欠拟合分类器"的那点空间也没有。

→ 架构 A（纯概念纠错）的预期下游增益为 0。它只能改善概念层指标，而这与下游 F1 是两件事。

## 4. 真正的误差是文本级共享因子，不是逐概念噪声

**隐式 vs 显式（y=1 子集）**：26 个概念的 P(yes) **全部**下移，均值 −0.121，最大 A01 −0.278。
专门为反讽设计的 C02 下移 −0.187——**加了表达类概念并没有堵住隐式缺口**。

**误差分解（test, n=2411, 总错误 501 = 20.8%）**

| 维度 | 结果 |
|---|---|
| expression=显式 | 错误率 12.8% |
| expression=隐式 | 错误率 23.8% |
| expression=转述 | 错误率 17.3% |
| topic=region | 错误率 24.3%（最高） |
| topic=lgbt | 19.0%（最低） |
| 长度 | 中间四分位最差 24.1%，两端约 18.5% |
| 平台 | tieba 20.9% / zhihu 20.6%，无差异 |

**错误形态**：FN 均值 mean(P_yes)=0.202，FP 均值 0.462。
- FN 中"所有概念都 <0.5"占 16.7%（39 条）
- FP 中"所有概念都 >0.5"占 **0.0%**（0 条）

→ 错误以"整体程度不足"为主，几乎不存在"单维度翻转"。**稀疏门控纠错（文档 10.4）针对的错误形态在数据里不存在。**

**噪声实验（test，固定噪声幅度 σ，改变概念间误差相关性 ρ）**

| ρ | σ=0.15 | σ=0.30 |
|---|---|---|
| 0（独立） | 0.7216 | 0.6766 |
| 1（完全共享） | 0.6787 | 0.6224 |
| 差值 | **−0.043** | **−0.054** |

同幅度下共享误差的代价是独立误差的 3–4 倍。26 维平均会自动抑制独立噪声，**只有跨概念共享的误差能存活下来**——正是 §4 那个隐式因子。

## 5. 数据陷阱（会直接影响后续实现）

- `toxic_type`：0=非有害，1=一般冒犯（无目标群体），2=仇恨（有目标）。**没有独立的 0 类**；把 0 当类别会造出 53% 的伪类。train 分布 4413 / 652 / 4535。
- `expression`：0=不适用，1=显式，2=隐式，3=转述。同样必须 mask，不能当四分类。
- 只有 toxic_type=2 的样本有 target one-hot；非目标类全 0。
- `topic` 对全部 9600 条都有值（含非有害），不是目标标签，只是话题分层。

## 6. 对研究方案的影响

1. **不要扩充概念集。** 26 维已复现 180 维性能，§4.3 的 7 个扩展方向缺乏依据（唯一例外见下条）。
2. **唯一有数据支持的概念缺口是「地域歧视/地域黑」**：region 错误率 24.3%，显著高于其他 topic，而概念集里只有 T03 一个地域条目。
3. **「引用/立场」概念没有独立起作用**：E 组与 B 组高度共线（E01–B07 r=0.885），立场未能从攻击中分离。§9.1 担心的"引用批判被过度激活"，实际表现是共线而非偏差。
4. **架构 A 应降级为 null baseline，不是最小可行版本。**
5. **若做架构 B，必须用 concept leakage 的标准检验**，不能只靠"冻结编码器 + 输出限于概念维"。冻结不阻断信息，限维不阻断信息。
6. **0.84 应彻底放弃**：公开 SOTA ≈ 83.8（MacBERT+ToxiTrace），本管线 test = 0.7901。差距 4.8 点，且不是测量噪声造成的。

## 7. 建议的替代主线

把论文从"我们提出纠错器"改成"**LLM 概念集的有效维度与不可纠正性**"：

- 主张 1：LLM 概念向量的标签相关信息近似 1–2 维，名义维度严重高估（26→1 只差 0.018；180→26 不降）。
- 主张 2：主要误差是文本级共享因子（implicitness），跨全部概念同向。
- 主张 3：因此逐概念纠正在信息论上无增益（附实验证明），有效路径是换概念轴或放弃严格瓶颈。
- 主张 4：给出联合评估协议（概念层 + 纠错行为 + 下游 + 共享因子诊断）。

这是负结果 + 诊断框架，比方法论文更稳、更省标注预算，且已有数据基本够支撑主张 1、2、3。
