# 性能提升路径：词法通道

数据：TOXICN 官方 split（train 9600 / test 2411），v8 26 概念（glm-4-9b-chat）
协议：5 折 CV 选阈值（折内），测试集阈值取 5 折均值；测试集数字无选择泄漏
环境：conda `toxicnew`

## 1. 主结果（严格协议，阈值取自 OOF，vectorizer 折内拟合）

| 特征 | CV Macro-F1 | test Macro-F1 | test AUC |
|---|---|---|---|
| 仅 26 概念（XGBoost） | 0.7989 | 0.7912 | 0.8727 |
| 仅 26 概念（LR） | 0.7914 | 0.7830 | 0.8684 |
| 仅字符 n-gram（1–3, LR） | 0.7509 | 0.7516 | 0.8283 |
| **概念 + 字符 n-gram（LR, C=4）** | **0.8105** | **0.8091** | **0.8952** |

净增益（对最强基线 XGBoost）：**+0.0179 Macro-F1，+0.0225 AUC**
净增益（对同模型 LR 基线）：**+0.0261 Macro-F1，+0.0268 AUC**

**修正说明**：先前报告的 0.8119 / +0.030 使用的是训练折 in-sample 预测选阈值，阈值有偏。
改为 OOF 阈值后为 0.8091，公平增量是 +0.018，不是 +0.030。

参照：ToxiCN 公开 SOTA ≈ 0.8383（MacBERT + ToxiTrace）。

## 4. 机制解释

概念集是**语义抽象**（"是否出现以辱骂性称呼攻击某人"），而标签在中文场景下大量由**词法-字形**决定。

ToxiCN 原论文的核心动机正是同音字、字形变形、黑话——而这恰好是 v8 概念集唯一无法表征的通道：概念问的是"有没有贬损"，不是"用没用'幕刃'这个词"。

这解释了此前全部观察：
- 180 → 26 概念性能不降：多的 154 个仍在同一语义通道内
- 后验纠错无效：纠正在语义通道内重整，词法通道始终缺失
- 隐式表达整体下移 −0.121：隐式文本恰恰缺少显式词法标记

## 5. 两个必做的对照（否则会被判"拼特征"）

1. **词法接地概念**：把词表写进概念定义再让 LLM 判断（保持严格 CBM）vs 词法残差直接进分类器（破坏 CBM）。两者之差 = 性能-可解释性前沿。
2. **随机选词 vs chi2 选词**：同预算下随机词的增益，用于证明增益来自"选对了词"而非"多给了参数"。

## 6. 剩余差距

0.809 vs 0.838，还差 2.9 点。词法通道补不了的部分是组合/上下文理解，需要编码器。

诚实结论：**严格 CBM 无法到达 SOTA，词法残差把差距从 4.7 点压到 2.9 点。**

## 7. 协议审计（针对 0.8119 那次的复核）

| 检查项 | 结果 |
|---|---|
| 训练/测试重复 | train 9600 条全唯一，test 2411 条全唯一，**0 条 test 文本出现在 train**；前 20 字重合仅 3 条 |
| 阈值来源 | 原实现取训练折 in-sample 预测（有偏）→ 改 OOF 后 test 0.8119→0.8091 |
| vectorizer 拟合范围 | 原实现全训练集拟合 → 改折内后差异 <0.001 |
| 特征块范数 | 词法块行范数 1.00，概念块 2.30（概念被隐式加权 2.3×）→ 拉平后 test 0.8097，无实质差异 |
| C 敏感性 | C=0.25→0.7881, 1→0.7963, **4→0.8091**, 16→0.8154；CV 选 C=4 |
| CV/test 一致性 | CV 0.8105 vs test 0.8091，无过拟合迹象 |

## 8. 编码器天花板与三通道融合（补充实验）

本地 `D:/models/chinese-macbert-base` 微调（8640 训练 / 960 dev，3 epoch，lr 2e-5，maxlen 128）：

| 系统 | test AUC | test Macro-F1 | 备注 |
|---|---|---|---|
| 概念 only | 0.8727 | 0.7912 | 严格 CBM |
| 词法 only（字符 1–3gram） | 0.8283 | 0.7516 | |
| 概念 + 词法 | 0.8952 | 0.8091 | 可审计 |
| **MacBERT 微调** | 0.8802 | 0.8035 | dev 0.8119；单配置未调参，应视为下界 |
| 融合：概念+词法 LR × MacBERT，等权平均 | **0.9070** | 0.8281* | |
| 融合：rank 平均 | **0.9078** | 0.8297* | |

\* 融合的 F1 使用测试集上最优阈值，属**诊断上界**，非可达结果。AUC 无阈值，可直接比较。

**关键观察**
- 三条通道互补：两两组合都高于任一单通道，AUC 从 0.895 提到 0.907。
- 但边际递减：概念+词法已到 0.809，**再加一个完整编码器只到 0.83 量级**。
- 微调 MacBERT 在本环境下低于概念+词法 LR，说明"公开 SOTA 0.838"不是随手可复现的，需调参与词典增强（原文的 TKE 正是词法通道，+1.0）。

## 9. 达到 0.84 需要多少改动（第一性核算）

当前 457 个错误 / 2411，F1 0.8096。逐条修正最自信的错误：

| 修正错误数 | F1 |
|---|---|
| 25 | 0.8201 |
| 50 | 0.8306 |
| **73** | **0.8411** |
| 100 | 0.8515 |
| 200 | 0.8932 |
| 457 | 1.0000 |

**→ 达到 0.84 需要修正 73/457 = 16% 的错误，错误率从 19.0% 降到 15.9%。**

错误构成：
- 极自信反向 57 条（2.36%），疑似标签错误，理论上不可修正
- 剩余 400 条中需修正 73 条（18%）
- 457 条错误里 **40.9% 不含任何 top-300 辱称项**，词法通道补不了
- 59.1% 含辱称项但模型仍错，多是语境翻转（引用/批判）或标签问题

结论：**0.84 ≈ 公开 SOTA + 0.002，是一个"成为该 benchmark 最强模型"的目标，不是工程调优目标。**
